## 主要变更

- **会话日志默认不再写真值**：新增 `restoreLog` 开关，默认关闭。回复里的占位符原样进入会话日志，agent 拿到的也是占位符，本地日志不再出现被脱敏的明文；需要旧行为（agent 与日志都拿到真值）时在配置页打开「会话日志写入真值」，打开前会二次确认真值会随同步、备份、分享、导出带走。开关在请求发出时取值，正在进行的调用按发出时的设置跑完（ADR-0003）。
- **统计与记录如实反映开关**：`/privacy status` 与统计卡在 `restoreLog` 关闭时把「还原」显示为「已关闭」，不再给出恒为 0 的数字；记录卡对「回复里有值表不认识的占位符」这类记录标出 `?N` 并在展开时说明原因，不再把它置灰成无事发生。
- **配置页说明修正**：`shape`、`maskKeys` 与 `toolGuard` 的说明写明只在 `restoreLog` 打开时才有还原发生，`toolGuard` 关闭时不会生效，避免把外发保护当成默认已启用。
- **升级注意**：默认行为翻转，升级后 agent 拿到的是占位符。依赖真值的任务（例如排查「这个 token 为什么 401」）需要打开 `restoreLog`。
- **内部**：多语言字典拆成 `locales/zh.ts` 与 `locales/en.ts`（`locales.ts` 只留 `NS`、`DICTIONARIES`、`T` 与再导出）；ADR-0003 按开关改写并补更新说明，ADR-0014 / 0021 / 0025 补充；`pnpm verify` 270 个测试。

## English

- **The session log no longer holds real values by default**: a new `restoreLog` switch, off by default, leaves a reply's placeholders as they are — the agent gets placeholders and the local session log holds no masked plaintext. For the old behaviour (the agent and the log both get the real values), turn on 「会话日志写入真值」 in the config page; it asks first and says the values travel with sync, backups, shares and exports. The switch is read when a request goes out, so a call in flight runs under the setting it went out with (ADR-0003).
- **Statistics and records tell the truth about the switch**: with `restoreLog` off, `/privacy status` and the statistics card show "Off" for restored places instead of a constant 0; a record that exists only because the reply had placeholders the value table knows nothing about is marked `?N` and explains itself when opened, instead of being dimmed as if nothing happened.
- **Corrected config-page text**: the notes for `shape`, `maskKeys` and `toolGuard` now say a reply is only put back with `restoreLog` on, and that the tool guard never runs with it off, so the guard is not mistaken for something on by default.
- **Upgrade note**: the default is flipped — after upgrading, the agent gets placeholders. Tasks that need the real value (working out why "this token gets a 401", say) need `restoreLog` on.
- **Internal**: the dictionaries are split into `locales/zh.ts` and `locales/en.ts` (`locales.ts` keeps `NS`, `DICTIONARIES`, `T` and the re-exports); ADR-0003 is rewritten for the switch with an update note, and ADR-0014 / 0021 / 0025 have supplements; `pnpm verify` 270 tests.
