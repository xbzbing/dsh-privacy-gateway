## 主要变更

- **模型文件名不再被当成密钥**：字段的值是文件名形状、且扩展名属于已知的文件类型（模型权重 `safetensors`/`gguf`/`ckpt`/`pt`/`bin` 等，以及压缩包、图片音视频、文档数据）时原样发出。ComfyUI 这类工具导出工作流会写出大量 `$key='…bf16.safetensors'`，之前这些模型文件名被换成同形假 key，agent 认不出模型、统计卡里多出 SECRET；现在不会再换（#1）。
- **状态目录按实例隔离**：HMAC key、脱敏记录与会话名单改放在当前实例自己的目录（`~/.dsh/profiles/<profile>/plugin-data/dsh-privacy-gateway/`），同一台机器上跑多个实例时不再互相写进对方的记录、统计和会话开关。没有 profile 时退回 `~/.dsh/privacy-gateway/`，`DSH_PRIVACY_GATEWAY_HOME` 仍然优先；启动日志会打出实际使用的目录。旧的 `~/.dsh/privacy-gateway/` 不再读取，要保留占位符把它拷到新目录（ADR-0027）。
- **内部**：规则新增 `fileNameValue`，在 `fieldAt` 里与 `pathValue`、`versionValue` 等并列，因此对所有按字段名找值的 SECRET 规则一致生效（ADR-0026）。

## What changed

- **A model's file name is no longer taken for a secret**: when a field's value has a file name's shape and an extension of a known kind (model weights such as `safetensors`, `gguf`, `ckpt`, `pt`, `bin`, plus archives, pictures, sound and video, documents and data), it goes out as it is. Tools like ComfyUI dump a workflow with plenty of `$key='…bf16.safetensors'`; those model file names used to become same-shape fake keys, so the agent could not name the model and the records collected SECRETs. They stay as they are now (#1).
- **State is kept per instance**: the HMAC key, the masking records and the session list now live in the current instance's own directory (`~/.dsh/profiles/<profile>/plugin-data/dsh-privacy-gateway/`), so two instances on one machine no longer write into each other's records, counts or session switches. A run with no profile falls back to `~/.dsh/privacy-gateway/`, and `DSH_PRIVACY_GATEWAY_HOME` still wins over both; the startup log names the directory in use. The old `~/.dsh/privacy-gateway/` is not read any more: copy it over to keep placeholders (ADR-0027).
- **Internal**: rules gained `fileNameValue`, which sits in `fieldAt` next to `pathValue` and `versionValue`, so it applies to every SECRET rule that looks for a value by its field's name (ADR-0026).
