## 主要变更

- **修复：cookie 对象只脱敏 `value`，`domain`、`path`、`expires` 不再被当成 cookie**：`cookie={"name": …, "value": …, "domain": "…", "expires": "…"}` 这种对象，原来被当成「按 cookie 名索引的 dict」逐对读，对象自己的字段也进了脱敏——`domain` 的主机名、`expires` 的时间戳、`path` 的路径都被当成 cookie 值，随后进了知识表，此后每个请求都在任意位置以 `known` 命中。表现是记录里冒出「kind=COOKIE、占位符却像 IP/域名」的行（回环地址、主机名、ISO 时间戳），统计里 COOKIE 分布大半是假阳性；开 `shape` 时假值本身也是地址形状，更难辨认。本机实测一个回环地址就被记到 260 条记录、4 个会话、12333 处。现在只要对象有 `name` 与 `value` 两个字段就按 cookie 对象处理，只脱敏 `value`（ADR-0010）。
- **修复：cookie 对象后面跟着的 JSON 不再被一起当成 cookie**：对象的范围原来取「下一个 `}`」，同一段文本里紧随其后的记录 JSON（`{"key": …, "time": …}`）因此被圈进来，`time`、`host`、`session`、`model`、`role` 这些字段的值都被学成了 cookie（本机实测 19 个时间戳、703 条记录）。现在按配对的 `}` 取范围，引号里的 `}` 不算结束；值是变量（`"value": value`）时也没有值可脱。

## English

- **Fixes: a cookie object masks its `value` only; `domain`, `path` and `expires` are no cookies**: an object such as `cookie={"name": …, "value": …, "domain": "…", "expires": "…"}` was read as a dict of cookies by name, field by field, so the object's own fields were masked too — the `domain`'s host, the `expires`' timestamp and the `path` were taken for cookie values and entered the value table, after which every request matched them by `known` wherever they appeared. The symptom: records naming `kind=COOKIE` over what looks like an IP or a domain (loopback addresses, host names, ISO timestamps), and a COOKIE distribution in the stats that is mostly false positives; with `shape` on, the made-up stand-in is address-shaped as well, which makes it harder still to recognise. On one machine a single loopback address reached 260 records, 4 sessions and 12333 places. An object that has both a `name` and a `value` field is now read as a cookie object, and only its `value` is masked (ADR-0010).
- **Fixes: the JSON after a cookie object is no longer taken for cookies**: the object's extent used to be "the next `}`", so a record's JSON following it in the same text (`{"key": …, "time": …}`) was swallowed with it, and the values of `time`, `host`, `session`, `model` and `role` were learned as cookies (19 timestamps over 703 records on that machine). The extent is now the matching `}`, a `}` inside a quoted value does not end it, and a value that is a variable (`"value": value`) has nothing to mask.
