## 主要变更

- **堵住脱敏盲区**：`<env>` 块的保护只作用于宿主写的系统提示词与 `system` / `instructions` / `systemInstruction`；用户消息、工具结果和工具参数里的 `<env>` 不再让后面的内容整段跳过脱敏。`url` / `image_url` 里重复出现的已脱敏值会换成同一个占位符，带签名的 URL 仍整段保留。`DB_PASSWORD=…` 这类具名赋值接受纯字母长口令和 10 位以上纯数字口令；embeddings 的字符串 `input` 与 completions 的字符串 `prompt` 现在也按模型请求脱敏（ADR-0004、ADR-0001、ADR-0036）。
- **还原更可靠**：回复里的 JSON 键、跨 chunk 的 SSE 事件、带转义引号的 cookie 值都能正确还原；值表按长度建索引，占位符冲突时失败关闭，不同值不再混成同一个占位符。
- **`/privacy` 如实反映配置**：配置里关闭脱敏时，`/privacy on` 不再声称已开启，状态里会写明「配置：脱敏关闭」；`/privacy off` 同时清掉运行开关，之后配置恢复也不会在用户不知情时自动开启。
- **配置页**：配置还在读取或读取失败时会显示状态，provider 列表可重试；计数器保存失败时保留用户输入，不再回滚成旧值。
- **统计卡与供应商视图**：跨版本的记录字段逐项校验，未知 finder 原样显示；供应商视图读取失败时给出原因；收起的分组在只脱敏键名时显示「只脱敏键名」，最近记录标题改为「最近 N 条」。
- **会话开关**：切换结果落盘失败时留在内存，下一次成功保存一并写入，不再因一次写失败丢掉选择。
- **内部**：undici 升级到 8.12.4；新增 ADR-0036，ADR-0001 / 0004 / 0029 补充；`pnpm verify` 264 个测试。

## English

- **Closed masking gaps**: `<env>` protection now applies only to text the host writes (the system prompt and `system` / `instructions` / `systemInstruction`); a `<env>` in a user message, tool result or tool argument no longer sends the rest of that string unmasked. A value already masked is masked again with the same placeholder inside `url` / `image_url`, while a signed URL still goes whole. Named assignments such as `DB_PASSWORD=…` now accept long letters-only passphrases and numbers of 10+ digits; embeddings' string `input` and completions' string `prompt` are now treated as model requests (ADR-0004, ADR-0001, ADR-0036).
- **More reliable restoration**: JSON keys in replies, SSE events across chunks and cookie values with escaped quotes are restored correctly; the value table is indexed by length and fails closed on a placeholder collision, so distinct values no longer share one placeholder.
- **`/privacy` tells the truth about the configuration**: when masking is off in the settings, `/privacy on` no longer claims it is on and the status says "Config: masking off"; `/privacy off` also clears the run switch, so re-enabling the configuration later does not turn masking on behind the user's back.
- **Configure page**: a configuration still being read or one that failed now says so, and the provider list can be retried; a count field keeps what the user typed when a save fails instead of rolling back to the old number.
- **Statistics card and vendor view**: records from another version have every drawn field checked and an unknown finder keeps its name; the vendor view gives the failure reason; a folded group says "Keys only" when that is all it masks, and the recent list's heading is now "Latest N".
- **Session switches**: a choice that could not be written stays in memory and goes in with the next successful save, instead of being lost.
- **Internal**: undici 8.12.4; ADR-0036 added, with supplements to ADR-0001 / 0004 / 0029; `pnpm verify` 264 tests.
