## 主要变更

- **占位符不再和模板语法撞车**：脱敏后的值现在是 `⟦DSH_REDACTED:KIND_xxxxxxxx⟧`——`⟦`/`⟧`（U+27E6/U+27E7）划出边界，`DSH_REDACTED` 是固定命名空间。agent 一眼能看出「这是网关取走的值，我手上没有真值」，不会再把它当口令去 `openssl enc -d`，失败后顺着错的前提推断「用户口令记错了」；Go template、Helm、Jinja2、Vue 配置里本来就有的 `{{…}}` 也不会再被认成网关占位符，统计卡上「值表里没有的占位符」那条假告警随之消失（#2）。
- **旧格式不再还原**：升级前会话里的 `{{KIND_xxxxxxxx}}` 现在是普通历史文本——不生成、不识别、不还原、也不计 `unmapped`。值表只在内存（ADR-0002），升级后本来就是空的，没有需要迁移的映射。
- **隐私保护标签页显示版本号**：「本会话脱敏」右侧的灰色小字是 host 半的版本号。装完刷新页面看到 `v0.3.0`，说明新代码已经生效；看不到就是还在跑旧进程，按 README 的「卸载再装」或重启 dsh 一次。
- **修复**：同一条回复里出现多个占位符时，逐条识别的正则会把上一次匹配的位置带进下一次，后面的占位符就漏识别了；嵌套 JSON 里转义成 `\u27e6` / `\u27e7` 的括号现在也能还原。
- **内部**：占位符协议集中到新增的 `src/redact/placeholder.ts`，掩码、值表、还原、toolGuard 共用一份，不再各写一份正则；单条占位符长度上界 37 → 48，流式尾部上界同步；值表识别 kind 时不再假设前缀恰好两个字符（ADR-0037）。

## English

- **Placeholders no longer collide with template syntax**: a masked value now reads `⟦DSH_REDACTED:KIND_xxxxxxxx⟧` — `⟦`/`⟧` (U+27E6/U+27E7) draw the boundary and `DSH_REDACTED` is a fixed namespace. An agent can tell at a glance that the gateway took this value and it has no plaintext, so it no longer feeds the placeholder to `openssl enc -d` and then reasons back to "the user mistyped their passphrase"; and a `{{…}}` that Go template, Helm, Jinja2 or Vue configs already contain is no longer read as one of our placeholders, which retires the false "a placeholder the value table does not know" warning on the statistics card (#2).
- **The old format is no longer restored**: `{{KIND_xxxxxxxx}}` in sessions from before the upgrade is ordinary history text now — we do not write it, read it, restore it or count it as unmapped. The value table lives in memory only (ADR-0002), so it is empty after any upgrade anyway and there is nothing to migrate.
- **The Privacy tab shows the version**: the small grey text beside the session switch is the host half's version. After installing, refresh and look for `v0.3.0`: that means the new code is live; if it is missing, the old process is still running — reinstall as the README's "uninstall then install" describes, or restart dsh once.
- **Fixes**: when a reply carried several placeholders, the per-match regex carried the previous match's position into the next one and silently skipped the rest; brackets escaped as `\u27e6` / `\u27e7` inside nested JSON are restored too now.
- **Internal**: the placeholder protocol now lives in the new `src/redact/placeholder.ts`, shared by masking, the value table, restoring and the tool guard instead of one regex per module; the longest placeholder grew from 37 to 48 characters with the stream tail bound following it; reading a kind no longer assumes the prefix is exactly two characters (ADR-0037).

- `pnpm verify` green: typecheck + 281 unit tests; `assert-pack` passed (11 required files, 7 manifest targets)
- Key regressions: a placeholder is not masked again by our own SECRET rule (the colon form `⟦…:…⟧` would be, and the value table would lose the mapping; the casing and escaped forms are held to the same rule); a `{{SECRET_…}}` belonging to the masked content itself passes through untouched with `unmapped` at 0 (the original scenario of issue #2); `\u27e6…\u27e7` escapes are restored; the old `{{…}}` is not
