## 主要变更

- **配置页说清了同形假 key 的边界**：值不足 8 个字符，或含字母、数字与 `-` `_` `.` 以外的字符时，仍用 `{{…}}` 占位符。配置页说明、README 和插件详情页都写明了，不再容易误解成「开了开关就全都换」。
- **记录表格更好读**：「模型 / host」列封顶 200px，让出来的宽度给「来源」，长标题不再被截成 `…RE…`。
- **退出时不再丢最后一批记录**：插件关闭时等记录写完再返回，而不是把写入留在后台。
- **内部**：npm 发布只走 OIDC，不再保留 `NPM_TOKEN` 兜底；`release.yml` 增加 `oidc-check`，可用 `gh workflow run release.yml -f check=true` 验证 trusted publisher 登记。

## What changed

- **The Configure page now spells out where same-shape fake keys stop**: a value under 8 characters, or holding anything but letters, digits, `-`, `_` and `.`, keeps its `{{…}}` placeholder. The setting's description, the README and the plugin's detail page all say so, so the switch no longer reads as "everything becomes a fake key".
- **The records table is easier to read**: the 「模型 / host」 column is capped at 200px and the width goes to 「来源」, so long titles are no longer cut to `…RE…`.
- **The last records are no longer lost on shutdown**: closing the plugin now waits for the records to be written instead of leaving the write in the background.
- **Internal**: npm publishing goes through OIDC only, with no `NPM_TOKEN` fallback; `release.yml` gained an `oidc-check` job, run with `gh workflow run release.yml -f check=true` to verify the trusted publisher.
