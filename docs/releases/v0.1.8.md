## 主要变更

- **统计卡能看懂 kind / finder，明细表可以按它们筛选**：分布图的标题和每个名字（`SECRET`、`known` 等）悬停时有说明，第 7 行合计写明是「其余 kind / finder / host」；展开一条记录后，明细表的 kind / finder 列头是筛选菜单，两列取交集，选「全部」取消，只影响显示。悬停卡按宿主官方组件的固定宽度和深色底排版、配色（ADR-0035）。
- **内部**：新增 ADR-0035；记录格式、统计口径与 host 行为不变；README / README.en 与插件详情页中英同步。

## 安装

```bash
# 正式版（npm）
dsh plugin --profile web add dsh-privacy-gateway@0.1.8

# 同一版本的 GitHub Release 附件
dsh plugin --profile web add https://github.com/xbzbing/dsh-privacy-gateway/releases/download/v0.1.8/dsh-privacy-gateway-0.1.8.tgz
```

## English

- **The statistics card explains kind and finder, and the values table filters by them**: hovering a distribution's title or a name (`SECRET`, `known` …) explains it, and the seventh row says it sums the other kind / finder / host; in an opened record, the kind and finder column heads are filter menus — both narrow together, 「全部」 (All) clears them, and only what is shown changes. The hover cards are laid out and coloured for the host card's fixed width and dark surface (ADR-0035).
- **Internal**: ADR-0035 added; the record format, the counting rules and the host behaviour are unchanged; README / README.en and the plugin's detail pages are in step in both languages.
