## 主要变更

- **修复：加密算法的名字不再被当成密钥脱敏**：Kafka 配置 `'once_kafka_token.scram_mechanism': 'SCRAM-SHA-512'` 这类值，因为字段名里有 `token`，被当成秘密，`shape` 打开时还会换成同形的随机串——工具输出里的配置和 git 里的对不上，排查的人会先怀疑配置被人改过。现在按闭集词表识别算法名（`scram`、`sha`、`aes`、`gcm`、`pbkdf`、`tls`……），整串都由这些公开词汇和数字构成就原样发出，不进记录、不进值表；词表与秘密字段名不相交，随机串照旧脱敏（ADR-0033）。
- **文档**：README 加题图、功能章节与安全提醒，安装说明改为三种免重启的更新方式，去掉已发布状态行，Release 示例跟到最新版本；英文版逐条跟随。

## English

- **Fixes: the name of a cryptographic algorithm is no longer masked as a key**: a value such as Kafka's `'once_kafka_token.scram_mechanism': 'SCRAM-SHA-512'` was taken for a secret because its field name holds `token`, and with `shape` on it became a made-up random string of the same form — the config in a tool's output no longer matched the one in git, and whoever debugged it first suspected the config had been edited. An algorithm's name is now recognized from a closed vocabulary (`scram`, `sha`, `aes`, `gcm`, `pbkdf`, `tls` …): a value built only of those published words and digits goes out as written, into neither the records nor the value table, while a random string is still masked; the vocabulary and the secret field names do not overlap (ADR-0033).
- **Docs**: the README gained a banner, a features section and a security reminder, the install note now names the three ways to update without a restart, the published-status line is gone, and the Release example follows the latest version; the English version follows it item by item.
