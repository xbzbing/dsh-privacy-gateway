## 主要变更

- **README 增加原理图**：用 mermaid 画出网关这一个拦截点的两个方向——发给模型前密钥、凭据、个人信息换成占位符，回复里的占位符默认不还原、原样进会话日志；旁路只记元信息。中英 README 各一张，配三条对应说明。
- **隐私保护空状态显示原理图**：本会话还没有记录时，标签页的空白处显示一张内联 SVG 示意图（agent → 隐私网关 → 模型服务，回复原路返回），网关用品牌紫、模型服务用绿色、占位符标签用琥珀色标出「默认不还原」。图跟随主题配色、随面板宽度缩放，不加载任何图片资源；有记录时仍是原来的统计与列表。
- **内部**：本次只有文档与空状态展示的改动，脱敏与还原行为、配置项、记录格式都没有变化；`pnpm verify` 270 个测试。

## English

- **A diagram in the README**: mermaid now draws the gateway's one interception point in both directions — secrets, credentials and personal data become placeholders before a request leaves, and by default a reply is not restored, so the session log keeps the placeholders; the side channel keeps metadata only. One diagram in each README, with three matching notes.
- **A diagram in the Privacy tab's empty state**: when a session has no records yet, the blank tab shows an inline SVG (agent → privacy gateway → model service, and the reply on the way back), with the gateway in brand violet, the model service in green and the placeholder tags in amber to flag that nothing is restored by default. It follows the theme's colours, scales with the panel and loads no image asset; once there are records the usual statistics and list come back.
- **Internal**: documentation and empty-state presentation only — masking and restoring, the configuration and the record format are unchanged; `pnpm verify` 270 tests.
