# 隐私网关

在 dsh 的进程里装一层脱敏网关：发给模型的请求里出现密钥、令牌、cookie 等敏感值时，先换成占位符再发出；模型回复里的占位符默认原样交给 agent、原样写进会话日志，不将它们还原成真值，打开 `restoreLog` 才在落盘前换回真值。用户输入和工具输出早于网关落盘，仍可能在会话日志里包含原文。

## 功能

- **脱敏**：API key（OpenAI、Anthropic、GitHub、AWS、阿里云、腾讯云等前缀）、JWT、PEM 私钥、URL 和字段里的密码、cookie；可选脱敏邮箱、手机号、身份证号、银行卡号，以及自己配置的词。
- **回复占位符默认不还原**：回复里的占位符原样进会话日志和 agent；打开 `restoreLog` 后 JSON 回复整包还原，SSE 流式回复逐条事件还原，占位符被切在两条事件之间也能拼回。
- **保持缓存**：同一个值每轮都是同一个占位符，prompt cache 照常命中。
- **按 kind 选动作**：脱敏、照发并记录（warn），或整个请求不发（block）。
- **外带守卫**：`restoreLog` 打开时，工具调用参数里还原出真值、又指向本机以外的 host 时，告警，或者不还原。
- **同形伪装**：可选把密钥换成前缀、长度、字符类别都相同的假 key，模型看不出被脱敏过；不足 8 个字符或含特殊字符的值仍用占位符。
- **记录与统计**：只记脱敏和还原过的请求，记录里不写值本身；`/privacy` 命令查看状态和预览，插件详情页有统计卡，也可以在会话顶部打开「隐私保护」标签页。
- **历史记录查询**：统计卡下方的「记录查询」按范围与类型读取保留期内的记录，不受最近 200 条限制；扫描可分片续扫，已发布的页不随后续扫描改变，点开一条会重新核对盘上的那一行。
- **发出内容对照**：可选在内存里保留副本；受保护区域、allow 与未命中内容可能仍含敏感原文，副本与会话日志同等敏感，不是原始数据的安全导出。
- **失败不放行**：脱敏出错时请求不发出；`/privacy off` 可以临时关掉。
