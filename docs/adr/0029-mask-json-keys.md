# ADR-0029：脱敏也作用于 JSON 键

- 状态：Accepted（2026-11-02）
- 相关：`src/redact/json.ts`、`src/redact/mask.ts`、`src/config.ts`、`src/engine.ts`、`src/client/fields.ts`、ADR-0004、ADR-0008、ADR-0015、ADR-0024、ADR-0028

## Context

网关只把 JSON 的字符串**值**交给查找器，键从不参与脱敏。这留下两个口子，本质是同一个：

- 请求侧：`{"metadata": {"sk-…": …}}` 这种把密钥当键名用的身体，键名原样发给模型服务，比漏一个值更糟——键和值一样是内容。
- 记录侧：`at`/`elsewhere` 的路径由 body 的原始键拼成，所以这个键名会跟着路径写进 JSONL、统计卡和浏览器（ADR-0024 起 `at` 就有，ADR-0028 放大到每值最多 8 条）。

ADR-0028 把第二条记作已知局限并指出根因在请求侧。这份 ADR 修根因。

## Decision

- `walkJSON` 增加一个可选的键回调：每个对象键在被写出前问一次，返回替换文本就改写键字面量，返回值不变则整份 body 逐字节保持原样。数组下标不是键，不参与。
- `Masker.maskKey` 用与值完全相同的查找器、动作和占位规则处理键名：`secrets`、`personal`、`words`、`allow`、`actions`、`shape` 都照常生效。命中就是一个 `Hit`，占位符与「同一个值作为普通值出现」时相同，所以回复里无论它出现在键还是值的位置都能还原（还原本来就是全文本替换）。
- 四类键永不改动，理由是它们属于请求结构而不是内容：
  - 协议自身的键（`KEPT` 与 `isID`：`model`、`role`、`type`、`name`、`id`、`*_id` 等）。脱敏一个 `role` 会让供应商读不懂请求。
  - 工具定义下的键（`tools`、`response_format` 等 `DEF_KEYS` 之下）：那是供应商要读的 JSON Schema，属性名就是它的一部分。
  - 工具调用参数里的键（`input`、`args`）：那是工具自己的 schema，改名会让调用失败。
  - `protectTools` 打开时工具定义整段本就逐字节保留（ADR-0004），键也一样。
- 记录里的位置用「发出时」的键：`walkJSON` 同时维护原始路径和改写后的路径，前者给判断逻辑（`keepIn`、`argPaths`、`placeOf`），后者进 `Place.path`。所以记录写的是 `metadata.{{API_KEY_x}}.note`，与「查看发出内容」对得上，也不再带原始键名。按 warn/block 照发的键，位置里写它的占位符而不是它本身。
- 键上的替换计入 `n`（替换处），不只是值：一个键被换掉就是一个替换处。
- 新增配置项 `maskKeys`，默认**开启**，volatile，放在配置页「脱敏」组，关闭时确认框说明它会让读起来像密钥的键名原样发出（ADR-0021）。默认开启是因为：会触发它的 body 本来就是把敏感文本当键名，关掉只会继续泄露；而普通 body 的键（`messages`、`content`、`role`）不匹配任何查找器，字节不变。

## Consequences

- 只有当 body 里存在「读起来像密钥/个人信息」的键名时，请求字节才会改变；这类请求原本就在泄露。普通请求逐字节不变，测试里有一条专门盯着这一点。
- 键被换掉后，模型看到的是占位符（`shape` 打开时是同形假 key）。模型若在回复里沿用这个键，还原会把它换回真值；不沿用也不影响，因为占位符只在这一轮有意义。
- 同一个值既做键又做值时只占一个占位符、一条记录，位置分别是键处和值处——对用户来说这正是「它出现过的地方」。
- 自定义敏感词也作用于键名：如果有人把 `content` 这类结构键写进 `words`，请求结构会被改坏。这是自设配置的代价，`maskKeys` 开关和配置页的说明是逃生口；不为此维护一份跨供应商的结构键名单。
- ADR-0028 记的「路径里的键可能是敏感文本」这一局限就此消除，那里改为指向本 ADR。

### 补充（2026-11-11）：JSON 键也会还原

原文说「回复里无论它出现在键还是值的位置都能还原（还原本来就是全文本替换）」。这对 `restoreText` 成立，但 `restoreJSON` 只走字符串值，键不经过还原：模型若把占位符当 JSON 键写回来，agent 看到的是 `{{…}}`。现在 `restoreJSON` 也给 `walkJSON` 一个键回调，`KEPT` 之外的键照常还原并计数；`test/redact.test.ts` 同时断言 `restoreText` 与 `restoreJSON`。
